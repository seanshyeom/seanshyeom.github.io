# dwightshyeom.github.io

Personal academic website of Seungho (Sean) Yeom. Static HTML/CSS, served by GitHub Pages.
Layout adapted from [Jon Barron's website template](https://github.com/jonbarron/jonbarron_website).

- `index.html`: page content (intro, publications, projects)
- `stylesheet.css`: styles
- `images/`: photo, project GIFs, favicons
- `data/`: CV and course paper PDFs
